# Personal Developer Portfolio

A responsive personal portfolio website built with HTML, CSS and vanilla JavaScript for the ShadowFox Frontend Developer beginner-level project.

## Features

- Home / introduction section
- About section
- Skills and tools section
- Projects showcase
- Contact form with client-side validation
- Responsive desktop, tablet and mobile layouts
- Mobile navigation, smooth scrolling and reveal animations
- Accessible labels, focus states and reduced-motion support

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a browser.

No build tools or dependencies are required.

## Contact form note

The form validates the name, email and message in the browser, then opens the visitor's default email app using a `mailto:` link. It does not send, store or deliver messages by itself. For direct website submissions, connect a backend or a form service and protect any credentials.

## Deploy with GitHub Pages

1. Create a new public GitHub repository, for example `my-portfolio`.
2. Upload `index.html`, `styles.css`, `script.js` and `README.md` to the repository root.
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. Wait for GitHub Pages to publish. Your live URL will look like `https://YOUR-USERNAME.github.io/my-portfolio/`.

After editing the site, commit and push your changes. GitHub Pages will publish the update automatically.
